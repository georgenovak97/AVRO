# ADR 0001 — Python-only архитектура для AVRO

Статус: Accepted  
Дата: 2026-08-12

## Контекст

Family Browser и остальная логика расширения работают в pyRevit/IronPython.
Ранее в репозитории был C#-проект `AVRO.Core`, но в текущем рабочем потоке он не использовался как обязательный runtime-компонент.

Ключевые ограничения:
- поддержка Revit 2020–2025;
- быстрый деплой через git + Reload в pyRevit;
- минимизация хрупких межъязыковых контрактов между Python и DLL.

## Решение

Принимаем Python-only архитектуру как базовую.

- `AVRO.Core` не является частью целевой runtime-архитектуры.
- Новая функциональность реализуется в Python-модулях.
- Возврат к C# допускается только точечно и только после измерений, если найден узкий hotspot, который нельзя закрыть алгоритмом/кэшем в Python.

## Последствия

Плюсы:
- проще сборка и поддержка (нет обязательной компиляции DLL);
- быстрее итерации разработки;
- меньше рисков несовместимости при обновлении pyRevit/Revit.

Минусы:
- часть тяжёлых участков может потребовать более аккуратной оптимизации (кэш, batching, I/O);
- потенциальный переход к mixed-architecture в будущем потребует отдельного ADR.

## Guardrails

- Не добавлять новый C#-слой без ADR и профилирования.
- Для любого предложения «ускорить через C#» требовать baseline-метрики и сравнение после прототипа.
